    Guide d'utilisation

    Ce guide explique, étape par étape, comment remplacer le cahier par le logiciel. Touchez un titre pour l'ouvrir.

    1. Comprendre l'écran

    En bas de l'écran, 5 boutons :

    • Commandes : la liste des commandes d'un jour et ce qu'il faut cuire.
    • Clients : chaque client avec son historique et ce qu'il doit.
    • Nouvelle (bouton rond vert) : noter une commande.
    • Bilan : les ventes et l'argent encaissé.
    • Réglages : les prix, la sauvegarde et ce guide.
    2. Noter une commande

    Quand un client appelle :

    1. Touchez Nouvelle.
    2. Écrivez le nom du client. S'il a déjà commandé, son nom apparaît pendant que vous tapez.
    3. Touchez + pour le nombre de petits et de grands pains. Le montant se calcule tout seul.
    4. Vérifiez le jour de la commande. Ajoutez l'heure, le téléphone ou une remarque si besoin.
    5. Choisissez Retrait ou Livraison.
    6. Si le client a déjà payé, cochez Déjà payé.
    7. Touchez Enregistrer la commande.
    Il faut au moins un nom et un pain (petit ou grand), sinon le logiciel affiche un message rouge.
    3. Savoir quoi cuire chaque jour

    Dans Commandes, le grand bloc vert indique le nombre de petits pains et de grands pains à cuire pour le jour choisi, le montant total et le reste à encaisser.

    • Les flèches ‹ › changent de jour.
    • Aujourd'hui et Demain sont des raccourcis. Le champ date permet de choisir un autre jour.
    • Les boutons En attente, Prêtes, Livrées, À encaisser filtrent la liste.
    • La case Chercher un client retrouve ses commandes sur tous les jours.
    3 bis. Voir les jours qui ont des commandes (calendrier)
    1. Dans Commandes, touchez Calendrier.
    2. Les jours qui ont des commandes sont colorés. Rouge : au moins une commande pas encore payée (le chiffre rouge dit combien). Orange : au moins une commande pas encore traitée, c'est-à-dire encore « En attente » (le chiffre orange dit combien). Vert : toutes les commandes du jour sont traitées et payées. Si un jour a les deux cas, il est rouge avec les deux chiffres.
    3. Touchez un jour pour afficher ses commandes. Les flèches ‹ › changent de mois.

    Quand vous notez une commande, une ligne sous le jour indique aussi combien de commandes sont déjà prévues ce jour-là.

    4. Suivre une commande, de la cuisson à la livraison

    Chaque commande passe par 3 étapes :

    1. En attente : la commande est notée.
    2. Prête : le pain est cuit. Touchez Marquer prête.
    3. Livrée : le pain est remis au client. Touchez Marquer livrée, ou Livrée si vous n'avez pas utilisé l'étape Prête.

    Une erreur ? Touchez Rouvrir pour revenir en arrière.

    5. Livrer et encaisser l'argent

    C'est l'étape la plus importante. Quand vous touchez Livrée, le logiciel demande : « Le client a-t-il payé ? »

    • Oui, payé : la commande affiche « Livrée · payée » en vert. C'est terminé.
    • Non, pas encore : la commande devient rouge et affiche « Livrée mais argent non reçu » avec le montant.
    Une livraison sans paiement reste signalée tant que vous n'avez pas touché « Encaisser ».
    6. Quand un client paie plus tard
    1. Sur l'écran Commandes, un bandeau rouge indique le nombre de livraisons sans paiement et la somme à récupérer, tous jours confondus.
    2. Touchez Voir pour afficher uniquement ces livraisons.
    3. Quand le client paie, touchez Encaisser sur sa commande. Elle disparaît de la liste.
    4. Pour relancer un client, touchez Rappel de paiement : le message est copié, il reste à le coller dans WhatsApp.
    7. Modifier ou supprimer une commande
    • Modifier : change le nom, les quantités, le jour, l'heure ou la remarque.
    • Supprimer : touchez une première fois, puis Confirmer la suppression dans les 4 secondes. Cela évite les suppressions par erreur.
    • Copier le bon : copie un petit bon de commande (client, quantités, total) à envoyer par WhatsApp.
    8. Les clients

    L'écran Clients se remplit tout seul : dès la première commande, le client est enregistré avec son nom et son téléphone, et on le retrouve à chaque ouverture. Quand vous écrivez un nom déjà connu, son téléphone se remplit tout seul. Pour chaque client :

    • le nombre de commandes et de pains achetés, et le total dépensé ;
    • « Doit … FCFA » en orange s'il reste de l'argent à recevoir, ou « À jour » en vert ;
    • Commander à nouveau : prépare une commande avec ses dernières quantités ;
    • Historique : toutes ses commandes passées.
    9. Le bilan des ventes

    L'écran Bilan montre, sur 7 jours, 30 jours, le mois ou depuis le début : le chiffre d'affaires, l'argent encaissé, le reste à encaisser, le nombre de petits et de grands vendus, un graphique par jour et les meilleurs clients.

    Copier les commandes (tableur CSV) copie les ventes pour les coller dans Excel ou Google Sheets.

    10. Changer les prix

    Dans Réglages, modifiez le prix du petit et du grand. Le nouveau prix s'applique aux nouvelles commandes seulement. Les anciennes gardent le prix du jour où elles ont été prises, donc le bilan reste juste.

    11. Sauvegarder pour ne rien perdre

    Avec le fichier sur le téléphone, les commandes sont gardées dans le navigateur de ce téléphone, pas sur internet. Avec la page en ligne, elles sont enregistrées en ligne (la ligne sous « Sauvegarde », dans Réglages, indique laquelle des deux est active).

    1. Ouvrez toujours le logiciel avec le même navigateur (par exemple Chrome).
    2. Ne videz pas les données du navigateur.
    3. Une fois par semaine : Réglages, puis Copier la sauvegarde, puis collez le texte dans une note ou un message WhatsApp à vous-même.
    4. Pour récupérer vos données sur un nouveau téléphone : Restaurer une sauvegarde, collez le texte, puis touchez Restaurer.
    Sans sauvegarde, un changement de téléphone ou un nettoyage du navigateur efface les commandes.
    12. Astuces
    • Sur Android (Chrome) : menu ⋮, puis Ajouter à l'écran d'accueil, pour ouvrir le logiciel comme une application.
    • Notez la commande pendant l'appel : c'est plus sûr que de s'en souvenir plus tard.
    • Chaque soir, ouvrez Demain pour savoir combien de pains préparer.
    • Le bouton Changer le thème dans Réglages passe en mode sombre.
    • Ajouter 3 commandes d'exemple (Réglages) sert à s'entraîner. Ensuite, touchez Réinitialiser le logiciel (Réglages, en bas) pour tout effacer et repartir de zéro. Il faut toucher deux fois, pour éviter les erreurs.
